- 品牌名称：Kensym®
- 身份标签：Visual · AI · Brand Designer
- 核心主张：让想象成为可见。
- 主要受众：品牌方、项目合作方、招聘方、创意行业同行
- 联系方式：future0224@126.com
- 所在地：Nanjing, China

## 5. 视觉与交互规范

| 维度 | 规范 |
| --- | --- |
| 主背景 | 近黑色 `#080808`，作品区略提亮为 `#0d0d0d` |
| 主文字 | 暖白色 `#f2f1ed` |
| 弱文字 | 灰色 `#9b9b98` |
| 强调色 | 荧光黄绿色 `#c8ff38` |
| 字体 | Manrope 为主，DM Sans 用于 Logo 与数字；中文回退 Microsoft YaHei |
| 布局 | 大屏最大内容宽度 1700px，左右留白约 48px；移动端约 20px |
| 动效 | 内容进入视区时由下向上淡入；图片 hover 轻微放大；按钮 hover 变为强调色 |
| 响应式 | 900px 以下转为单列或双列简化布局；520px 以下进一步压缩字号和留白 |

## 7. 内容维护建议

1. 新增作品时，先补齐封面、视频、类型、职责与编号，再加入首页项目数据。
2. 项目数量超过 6 个后，建议增加“全部作品”页或按短片、旅行影像、品牌内容分类，避免首页过长。
3. 每个项目后续可补充独立详情页，包含创作背景、职责范围、剧照、制作过程和最终成果。
4. 个人简介、数据统计、软件清单与联系信息应作为高频维护内容，保持与实际经历一致。
